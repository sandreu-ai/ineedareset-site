# RESET Storage & Organization Add-On Product Log

Last researched: 2026-06-03

Purpose: internal RESET sourcing/reference log for storage add-ons that may be advertised on the website and discussed with customers. Prices are live-market snapshots, not guaranteed vendor pricing. Re-check before quoting or buying.

Research limitation: Amazon product pages were accessible during this pass, so the first clean priced SKU set is Amazon-heavy. Home Depot returned an error page and Lowe’s returned access denied in the browser session; use this log as the working baseline, then re-check Home Depot/Lowe’s manually or from a normal browser before buying if you want local pickup/comparison pricing.

Important publishing note: retailer product photos are for internal reference/client explanation only unless licensing/affiliate/permission is confirmed. The website should use RESET-branded graphics/copy, not copied retailer photos.

## Recommended customer-facing offer structure

- Lead public offer: Storage & Organization Add-Ons, starting at $50.

## Margin / quote guidance

- Bike hook installation starting at $50 per bike has enough room if material cost is roughly $5–$22 per bike depending on hardware choice, but confirm wall/stud conditions.
- Storage bin package starting at $20 per bin is aligned with the Sterilite 4-pack snapshot (~$19/bin) but leaves little room unless labor is priced separately or bins are part of a larger package.
- Sports zone starting at $125 is reasonable when material is ~$70–$90 and assembly/placement is simple; complex sorting should be part of the main reset labor.
- Yard tool wall starting at $125 is reasonable with material around $30–$60 and straightforward wall mounting.
- Power tool charging station starting at $150 is reasonable with material around $35–$90, but do not imply electrical installation beyond using existing outlets/power strips.
- Storage rack + 4-bin system starting at $250 may be tight if using a premium shelf ($126.59) + premium bins ($75.99) before labor; better public wording is “starting at $275” or include it inside package upgrades. I recommend website package language instead of itemizing this too aggressively.
- Bronze/Silver/Gold package pricing should remain “starting at” until RESET has measured actual labor time across several installs.
